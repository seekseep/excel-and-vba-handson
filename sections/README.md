# 進め方

まず、どちらの環境で進めるかを選んでください。

::platform-choice

教材は Excel（VBA）が主ですが、Google スプレッドシート（Apps Script、以下 GAS）でも同じ課題に取り組めます。選ぶと、手順やコードが分かれる箇所が、すべてのページでその環境のものになります。たとえば次のコードは、選んでいる環境のものだけが表示されます。

:::::platform
::::excel
A1 のセルに「こんにちは」と書くマクロ（VBA）:

```vb
Sub Hello()
    Range("A1").Value = "こんにちは"
End Sub
```

VBE（`Alt` + `F11`）の標準モジュールに書いて、`F5` で実行します。
::::
::::sheets
A1 のセルに「こんにちは」と書くマクロ（GAS）:

```js
function hello() {
  SpreadsheetApp.getActiveSheet().getRange('A1').setValue('こんにちは');
}
```

「拡張機能」→「Apps Script」のエディタに書いて、「実行」を押します。
::::
:::::

あとから変えたいときは、画面右上のナビゲーションバー（テーマ切り替えの左）でも選べます。選んだ環境はブラウザが覚えておくので、次に開いたときもそのままです。

- 会社や学校の PC で Excel のマクロが禁止されている
- Excel を持っていない

という場合は、スプレッドシートで参加してください。VBA と GAS の書き方は [基本的な知識](./BASICS.md) にまとめてあります。

## 章と節

題材は架空の文房具店「そよかぜ文具店」の、月末の請求書づくりです。30 行の売上明細から顧客ごとの請求額を出し、5 社分の請求書を PDF にするまでを、手作業 → Excel 関数 → VBA と道具を持ち替えながら自動化していきます。

教材は 5 つの **章** でできていて、講義の章とハンズオンの章が交互に並びます。章はいくつかの **節** に分かれていて、左のサイドバーから順に進めます。第 3 章と第 5 章は同じ売上データを使います。

1. **そのExcel作業、本当に手作業が必要？**（講義）  
   今日の課題を確かめ、Excel 関数と VBA がそれぞれ何に向いているかを考えます。
2. **はじめてのマクロを動かそう**（講義＋実習）  
   マクロを書く画面を開き、セルの読み書きと変数を使った小さなマクロを動かします。自分で書いたマクロが動けば完成です。
3. **Excel関数をVBAで再現しよう**（ハンズオン）  
   SUM と SUMIF でやっていた集計を、くり返しと条件分岐で書き直し、デバッガーの使い方を覚えます。VBA で集計した結果をセルに出せれば完成です。
4. **VBAだからできること**（講義＋デモ）  
   シートを作る・飾る・保存するといった、関数ではできない操作を見ていきます。
5. **ボタンひとつで請求書を作ろう**（ハンズオン）  
   売上データから 5 社分の請求書シートと PDF を作り、ボタンから実行できるようにします。ボタンを押すと請求書ができれば完成です。

節ごとに、練習用のブックとその節までの完成コードを入れた ZIP があります。同じ章の節は同じブックで続けて進めるので、ダウンロードは章の最初の節だけで大丈夫です（途中から始めるときや答え合わせに、ほかの節の ZIP を使ってください）。
