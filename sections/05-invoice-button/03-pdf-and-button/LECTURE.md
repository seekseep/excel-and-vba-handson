# PDF にしてボタンから実行する

![ボタンを押す → マクロが動く → 請求書シートと PDF ができる](./images/00-thumbnail.svg)

5-2 の続きです。請求書を PDF にし、最後にボタンを自分で置いて（スプレッドシートではメニューに項目を足して）、マクロを登録する方法を覚えます。

:::download
[この節を始めるブックをダウンロード](./start.zip)
[サンプルのスプレッドシートをコピー](./spreadsheet)
:::

前の節から続けている人は、そのブックのまま進めてください。ここから始める人は、上のボタンから 5-2（明細を書き写す）を終えた状態のブックをダウンロードしてください。Excel では、マクロ入りのブック（`.xlsm`）を開くときに [マクロを有効にする](../../00-setup/01-excel/LECTURE.md#ダウンロードしたマクロ入りのブック) 必要があります。スプレッドシートでは、上の「サンプルのスプレッドシートをコピー」で自分のドライブにコピーを作り、「コードをダウンロード」の ZIP にある `gas/` のコードを Apps Script エディタに貼って、前の節を終えた状態にしてから進めてください。

## PDF にする

`Next c`（GAS は `for` の閉じ `}`）の直前、合計を書いたあとに、請求書シートを PDF にする処理を足します。

:::::platform
::::excel
```vb
        ' ブックと同じフォルダに PDF を書き出す
        pdfPath = ThisWorkbook.Path & Application.PathSeparator & "請求書_" & customerName & ".pdf"
        invoiceSheet.ExportAsFixedFormat Type:=xlTypePDF, Filename:=pdfPath
```

`Dim pdfPath As String` も足します。実行すると、ブックと同じフォルダに 5 つの PDF ができます。

:::warning[PDF が保存できないときは]
- **OneDrive に保存したブック** では `ThisWorkbook.Path` が `https://…` になり、PDF を書き出せないことがあります。ブックをデスクトップなど PC の中のフォルダに保存し直してください
- **Mac** では、初回に「フォルダへのアクセスを許可しますか」と聞かれます。「アクセスを許可」を押してください
:::
::::
::::sheets
Apps Script には Excel の `ExportAsFixedFormat` にあたる命令がありません。そこで、スプレッドシートの「ファイル」→「ダウンロード」→「PDF」と同じ URL を呼び出して PDF を受け取り、ドライブに保存する関数 `savePdf_` を用意します。

```js
function savePdf_(ss, sheet) {
  const url = 'https://docs.google.com/spreadsheets/d/' + ss.getId() + '/export' +
    '?format=pdf&size=A4&portrait=true&fitw=true&gridlines=false&gid=' + sheet.getSheetId();
  const response = UrlFetchApp.fetch(url, {
    headers: { Authorization: 'Bearer ' + ScriptApp.getOAuthToken() },
  });
  const folder = DriveApp.getFileById(ss.getId()).getParents().next();
  folder.createFile(response.getBlob().setName(sheet.getName() + '.pdf'));
}
```

この中身は理解できなくても大丈夫です。「シートを渡すと PDF にしてくれる部品」として使います（関数名の末尾の `_` は、実行する関数の一覧に出さないための Apps Script の決まりです）。

`createInvoices` の合計を書いたあとに、次の 2 行を足します。

```js
    SpreadsheetApp.flush();
    savePdf_(ss, invoiceSheet);
```

`SpreadsheetApp.flush()` は、ここまでの書き込みを確定させる命令です。これが無いと、書き込む前の空の請求書が PDF になることがあります。

初回はドライブと外部への接続の承認を求められます。

:::::

## ボタン（メニュー）から実行する

最後に、VBE やエディタを開かなくても実行できるよう、Excel ではシートにボタンを、スプレッドシートではメニューに項目を足します。

:::::platform
::::excel
「顧客」シートには、5-1 から使ってきた **請求書を作る** ボタンが置いてあります。このボタンは、練習用ブックを作るときに「押したら `CreateInvoices` を動かす」と登録しておいたものです。同じ手順で、5-2 の `DeleteInvoices` を動かすボタンを自分で置いてみましょう。

1. 「顧客」シートを開く
2. 「開発」タブ →「挿入」→ フォーム コントロールの **ボタン** を選び、**請求書を作る** ボタンの下の空いているところをドラッグする
3. 「マクロの登録」が開くので `DeleteInvoices` を選んで「OK」
4. ボタンを右クリック →「テキストの編集」で「請求書シートを消す」に変える
5. セルをクリックしてボタンの選択を外してから、ボタンを押す。請求書シートが消えれば成功です
6. **請求書を作る** を押して、請求書を作り直す

**請求書を作る** ボタンを右クリック →「マクロの登録」を開くと、`CreateInvoices` が選ばれているのを確かめられます。
::::
::::sheets
5-1 で書いた `onOpen` のおかげで、メニューの「請求書」→「請求書を作る」から `createInvoices` を動かせます。同じ手順で、5-2 の `deleteInvoices` をメニューに足してみましょう。

1. Apps Script エディタで、`onOpen` の `.addToUi()` の上に `.addItem('請求書シートを消す', 'deleteInvoices')` を足して保存する
2. スプレッドシートのタブを再読み込みする
3. メニューの「請求書」→「請求書シートを消す」を押す。請求書シートが消えれば成功です
4. 「請求書」→「請求書を作る」を押して、請求書を作り直す

メニューの項目と関数は、`.addItem('項目名', '関数名')` の 1 行で結び付いています。項目の順番は、`.addItem` を書いた順です。
::::
:::::

ボタン（メニュー）から実行したときの動きを、ブラウザ上で再現したデモで確かめましょう（ブックと同じフォルダには PDF が 5 つできます）。

::::
::::sheets
メニューの「請求書」→「請求書を作る」を押します（Apps Script エディタの関数の選択欄で `createInvoices` を選んで「▶ 実行」を押しても同じです）。

「ボタンを押す」「メニューを選ぶ」「ファイルを開く」のように、利用者の操作をきっかけにマクロを動かす仕組みを **イベント** と呼びます。ここでやったのは「ボタン（メニューの項目）が押されたら、このマクロを動かす」という登録です。GAS の `onOpen` も「開いたとき」というイベントで動いています。`Sub`（GAS は `function`）は単独でも、ボタンからでも、ほかのマクロからでも動かせる「手順のかたまり」です。

:::notice[マクロのボタンやメニューを配るときは]
ボタンやメニューを押す人は、マクロの中身を読まずに実行します。人に渡すブックでは、押すと何が起きるか（シートが消える、ファイルができる など）がわかる名前を付け、シートの近くにも書いておきましょう。
:::

## 発展（持ち帰り）

- **請求月を選べるようにする** — 顧客シートの空いたセルに「2026/10」のように月を書き、その月の明細だけを請求書にする（ヒント: `If` の条件に日付の比較を足す。`Month(日付)` で月が取れます）
- **明細が 20 行を超えたら** — テンプレートの明細欄は 20 行です。超えたときにどうするか（エラーにする、2 ページ目を作る）を考えて実装する
- **メールで送る** — 作った PDF を顧客に送るところまで自動化する。Excel なら Outlook、スプレッドシートなら `GmailApp` を使います。ただし誤送信は取り返しがつかないので、まず「下書きを作る」までにするのがおすすめです

::codeview[この章の完成コード]

:::faq

### ボタンの文字や大きさを直そうとクリックすると、マクロが動いてしまいます

ボタンを **右クリック** すると、マクロを動かさずにボタンを選択できます。選択した状態で、文字の編集や大きさ・位置の変更ができます。スプレッドシートのメニューは、項目名を `onOpen` の `.addItem` の 1 つ目の引数で直します。

### 作ったブックを人に渡したら、ボタン（メニュー）を押しても動きません

相手の Excel でマクロが無効になっています。メールやダウンロードで受け取ったブックは、Windows ではマクロがブロックされることがあり、ファイルを右クリック →「プロパティ」→「許可する」にチェックを入れてから開き直す必要があります。渡すときは「マクロを含むこと」と「何をするマクロか」を必ず伝えましょう。スプレッドシートは、共有された人も初回の実行時に承認が必要です。また、メニューは開いたときに `onOpen` が作るので、コードを直した直後はスプレッドシートを再読み込みしないと出ません。

### PDF の余白や、1 ページに収まるかどうかを調整したいです

Excel の `ExportAsFixedFormat` は、シートの **ページ設定**（印刷範囲・余白・拡大縮小）に従います。テンプレートのページ設定を「シートを 1 ページに印刷」などに整えておけば、コピーした請求書にもそのまま引き継がれます。GAS では `savePdf_` の URL の引数で調整します（`size` は用紙、`portrait` は向き、`fitw=true` は横幅に合わせる）。

### 顧客や明細が増えると、遅くなりませんか？

遅くなります。Excel では、最初に `Application.ScreenUpdating = False` を書いて画面の書き換えを止めるだけでも速くなります（最後に `True` に戻します）。GAS はセルの読み書き 1 回ごとにサーバーとやりとりするので、`getValues()` / `setValues()` でまとめて読み書きするのが効きます。また、GAS には 1 回の実行が 6 分までという制限があるので、大量の PDF を作るときは注意が必要です。

### PDF がどこにできたのか分かりません

Excel では、ブックと同じフォルダ（`ThisWorkbook.Path`）にできます。ブックを一度も保存していないと保存先が決まらないので、先に `.xlsm` で保存してから実行してください。スプレッドシートでは、そのスプレッドシートと同じ Google ドライブのフォルダにできます。

### 同じ名前の PDF がすでにあると、どうなりますか？

Excel の `ExportAsFixedFormat` は、確認なしで上書きします（その PDF を開いていると、上書きできずにエラーになります）。Google ドライブは同じ名前のファイルを何個でも置けるので、GAS の `createFile` は上書きせず、同じ名前の PDF が増えていきます。ファイル名に発行日を付けるか、作る前に古いファイルを消すと、どちらでも迷いにくくなります。

:::
