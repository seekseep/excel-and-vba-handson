## 止めて、変数を見る

コードを眺めて見つけられるかもしれませんが、ここでは **実行を途中で止めて、変数の中身を見る** やり方で探します。AI が書いたコードが期待どおりに動かないときも、同じやり方で原因を調べられます。

:::::platform
::::excel
1. **ブレークポイントを置く** — `total = total + Cells(i, 6).Value` の行の左の灰色の帯をクリックする（`F9` でも可）。茶色の丸が付きます
2. **実行する** — `SumTotalWithBug` の中で `F5`。ブレークポイントの行が黄色くなって止まります
3. **変数を見る** — 「表示」→ **ローカル ウィンドウ** を開くと、`i`、`total`、`lastRow` の今の値が一覧で出ます。コード上の変数にマウスを乗せても値が出ます
4. **1 行ずつ進める** — **`F8`**（Mac は `⌘` + `Shift` + `I`）を押すたびに 1 行だけ進みます。`i` と `total` がどう変わるかを見てください
5. **止める** — ツールバーの ■（リセット）で実行を止めます

最初に止まったとき、`i` はいくつでしたか？ データは 2 行目から始まるのに、`i` は **3** から始まっています。2 行目（1,250 円）が足されていなかったのです。`For i = 3` を `For i = 2` に直して、もう一度実行してください。
::::
::::sheets
1. **ブレークポイントを置く** — `total = total + ...` の行番号の左をクリックする。紫の丸が付きます
2. **デバッグ実行する** — 関数の選択欄で `sumTotalWithBug` を選び、**デバッグ** を押す（「実行」ではありません）。ブレークポイントの行で止まります
3. **変数を見る** — 右側の「デバッガ」パネルの「変数」に、`i`、`total`、`lastRow` の今の値が出ます
4. **1 行ずつ進める** — デバッガの **ステップ オーバー**（↷）を押すたびに 1 行だけ進みます。`i` と `total` がどう変わるかを見てください
5. **止める** — ■（停止）で実行を止めます

最初に止まったとき、`i` はいくつでしたか？ データは 2 行目から始まるのに、`i` は **3** から始まっています。2 行目（1,250 円）が足されていなかったのです。`let i = 3` を `let i = 2` に直して、もう一度実行してください。
::::
:::::

### ログに出して確かめる

止めずに、途中経過を書き出して確かめる方法もあります。

:::::platform
::::excel
`For` の中に次の 1 行を足して実行し、`Ctrl` + `G` で **イミディエイト ウィンドウ** を開きます。

```vb
Debug.Print i, Cells(i, 6).Value, total
```

1 行ごとに「行番号・金額・その時点の合計」が並びます。最初の行が `3` から始まっていることが一目で分かります。

イミディエイト ウィンドウには、式を直接打って確かめることもできます。`? Range("F2").Value` と打って `Enter` を押すと、F2 の値が表示されます。
::::
::::sheets
`for` の中に次の 1 行を足して実行し、下の **実行ログ** を見ます。

```js
console.log(i, sheet.getRange(i, 6).getValue(), total);
```

1 行ごとに「行番号・金額・その時点の合計」が並びます。最初の行が `3` から始まっていることが一目で分かります。
::::
:::::

:::notice[エラーで止まったときは]
- **Excel** —「実行時エラー」の小窓で **デバッグ** を押すと、エラーになった行が黄色く表示されます。その時点の変数をローカル ウィンドウで確かめてから、■ で止めて直します
- **スプレッドシート** — 実行ログの赤いエラーに「`コード.gs:5`」のように、ファイル名と行番号が出ます

どちらも「どの行で」「そのとき変数が何だったか」が分かれば、原因はかなり絞り込めます。AI に相談するときも、エラーの文面と、その行と変数の値を一緒に伝えると的確な答えが返ってきます。
:::

## これは関数で十分だった

ここまでで、関数で出した答えを VBA でもすべて再現できました。並べてみると、

| | 関数 | VBA |
|---|---|---|
| 書く量 | 式 3 つ | マクロ 3 つ |
| データを直したとき | 自動で計算し直す | もう一度実行する |
| 計算の根拠 | セルに残る | コードを読まないと分からない |

この集計に限っていえば、**関数のほうが向いています**。それでも VBA で書いたのは、ここで使った 3 つの道具が、関数ではできない処理の部品になるからです。

- `Cells(i, 列)` で行を順番に指す
- `For` でくり返す
- `If` で条件に合う行だけを選ぶ

第 5 章では、この 3 つをそのまま使って「顧客ごとに請求書のシートを作り、明細を書き写す」処理を作ります。
